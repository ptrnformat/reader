# Decisions

Newest first. Each entry records what was decided and why.

## 2026-11-22 — Initial scope

- **Viewer and printer only.** The main job is letting the person making a pattern view and print it, like the original Adobe Reader.
- **No recount or mismatch flags.** Correct counts are the designer's responsibility, and Writer handles them.
- **No row tracking.** Progress, counters and notes are out of scope.
- **Not offline.** It's a web tool. It still runs in the browser where possible, so files aren't uploaded.
- **Crochet and knitting first,** because those are what the CYC standards and Ravelry cover. Specialty forms like Tunisian come later.
- **Show written rows when there's no graph,** because Writer can save files without a graph when counts don't match.
